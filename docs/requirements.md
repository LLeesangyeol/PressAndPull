# Requirements

## App Concept

Press & Pull은 개인 운동 기록, 루틴 추천, 인바디 변화를 한 앱에서 관리하는 Android Native 앱이다.

## User Scenarios

1. 사용자는 오늘 수행한 운동명, 부위, 세트, 반복, 중량을 등록한다.
2. 사용자는 기존 운동 기록을 수정하거나 삭제한다.
3. 사용자는 인바디 측정일, 체중, 골격근량, 체지방률을 등록한다.
4. 사용자는 최근 기록을 바탕으로 추천 루틴을 확인한다.
5. 사용자는 앱을 종료 후 재실행해도 저장된 기록을 다시 확인한다.
6. 사용자는 회원가입 후 자신의 데이터만 확인한다.
7. 사용자는 운동 기록 화면에서 해당 운동 동작 모션과 핵심 큐를 확인한다.

## Functional Requirements

| ID | Requirement | Required |
| --- | --- | --- |
| F-01 | 운동 기록 CRUD를 제공한다. | O |
| F-02 | 인바디 기록 CRUD를 제공한다. | O |
| F-03 | 홈, 운동 기록, 루틴 추천, 인바디 화면을 제공한다. | O |
| F-04 | 입력값 검증 및 오류 메시지를 제공한다. | O |
| F-05 | 로컬 저장소에 데이터를 영속 저장한다. | O |
| F-06 | 최근 운동 부위와 인바디 상태 기반 추천 루틴을 제공한다. | O |
| F-07 | 로그인/회원가입 기능을 제공한다. | O |
| F-08 | 운동별 동작 안내 모션을 제공한다. | O |

## Non-Functional Requirements

| ID | Requirement |
| --- | --- |
| NF-01 | Android Native Kotlin + Jetpack Compose로 구현한다. |
| NF-02 | 앱 재실행 후에도 데이터가 유지되어야 한다. |
| NF-03 | 클라우드 동기화 확장 시 어디서든 접근 가능한 DB 구조를 사용한다. |
| NF-04 | 한국어 UI를 기본으로 제공한다. |
| NF-05 | 앱은 별도 서버 설정 없이 Android Studio Run으로 실행 가능해야 한다. |
